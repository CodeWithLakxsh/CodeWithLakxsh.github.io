# Security Policy

## Supported versions

Only the latest deployed version of the website (the `main` branch) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately:

1. If the repository has **Private vulnerability reporting** enabled on GitHub, use the **"Report a vulnerability"** button on the repository's **Security** tab.
2. Otherwise, contact the maintainer privately via Telegram: [t.me/codewithlaksh](https://t.me/codewithlaksh).

Please include:

- A description of the issue and its potential impact
- Steps to reproduce (or a proof of concept)
- Any affected files or URLs
- Your contact details (optional)

## What to expect

- Acknowledgment of your report as soon as possible.
- A status update once the issue has been triaged.
- Credit for the report if you would like it.

## Notes

- This site is fully static and hosts no user data. Sensitive configuration (keys, credentials) must never be committed to this repository.
- If you discover accidentally committed secrets, do not post them publicly — report them privately instead.
